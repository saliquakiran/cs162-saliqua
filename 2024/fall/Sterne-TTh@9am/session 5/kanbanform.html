# Normally, when a form is submitted in HTML, the browser sends the form data to a server and reloads the page. However, in this case, we don’t have a backend server to process the form data. # JavaScript was therefore used, which allows us to prevent the default form submission behavior (of page not working when a task was added) and handle everything on the client-side, keeping the page static. # As guided by ChatGpt, JavaScript allows real-time updates by allowing the user to add new tasks to the Kanban board dynamically. Instead of reloading the page, it directly manipulates the Document Object Model (DOM) to insert new tasks into the appropriate column.
